# study_organizer

공부하면서 모은 자료를 학문 > 분야 구조로 정리하는 개인 로컬 사이트.
파일을 업로드하면 Grok API(AI)가 제목/설명을 보고 "물리 > 양자역학에 저장할까요?"
라고 제안하고, 예/아니요로 답하면서 정리해나가는 방식.

## 기능
- 홈에서 분야(물리, 화학, ...) 클릭 -> 하위분야(양자역학, ...) 클릭 -> 파일 목록
- 파일 업로드 시 AI가 분류 경로 자동 제안 (예/아니요 선택)
  - "아니요"를 누르면 거절된 경로를 제외하고 다음으로 적절한 경로를 다시 제안
  - AI 제안 없이 직접 "물리 > 양자역학" 형태로 수동 입력도 가능
- 없는 분야는 자동 생성 (미리 만들어둘 필요 없음)
- 파일 검색 (제목/설명/원본파일명), 다운로드, 삭제
- 모든 데이터는 로컬에 저장: 파일 원본은 uploads/, 메타데이터는 study_organizer.db

## 설치 및 실행 (VSCode)
1. 이 폴더를 VSCode로 열기
2. 터미널에서:
   ```
   pip install -r requirements.txt
   ```
3. `.env.example`을 복사해서 `.env` 파일을 만들고, Grok API 키 입력:
   ```
   GROK_API_KEY=발급받은_키
   GROK_MODEL=grok-4
   ```
   - 키 발급: https://console.x.ai (유료, 사용량 기반 과금)
   - 모델명이 만료됐다면 https://docs.x.ai/docs/models 에서 최신 이름 확인
4. 서버 실행:
   ```
   python app.py
   ```
5. 브라우저에서 http://127.0.0.1:5000 접속

## API 키 없이도 쓸 수 있나?
가능. AI 제안 부분에 에러 메시지가 뜨지만, 그 아래 "직접 분류하기"에
"물리 > 양자역학" 형태로 입력하면 수동 분류로 동일하게 작동함.

## 파일 구성
- `app.py`            Flask 라우트 (진입점)
- `db.py`             SQLite - 계층형 카테고리 트리 + 파일 메타데이터
- `ai_classifier.py`  Grok API 호출, 분류 제안 (OpenAI SDK 호환 방식)
- `templates/`        HTML 템플릿
- `static/style.css`  스타일
- `uploads/`          업로드된 파일 원본 저장 위치 (자동 생성)

## 주의사항
- `.env` 파일은 절대 남에게 공유하거나 깃허브에 올리지 말 것 (API 키 유출)
- 로컬 개인용 설계라 로그인/권한 기능은 없음
- AI 제안은 참고용이며 최종 판단은 사용자가 함 (예/아니요 구조인 이유)
